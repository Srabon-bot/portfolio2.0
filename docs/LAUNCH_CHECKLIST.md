# Launch & Acceptance Checklist (PRD §15)

Complete verification checklist before sharing the portfolio with recruiters and interviewers.

---

## 1. Core Acceptance Criteria

- [x] **Six Sections on Home**: TopBar, Hero, About, Skills, Projects, Contact, Footer.
- [x] **Hero Image**: Single squared photo with floating levitation, ambient pulsing aura, tech brackets, and status pill.
- [x] **Only Image**: No duplicate photo in the About section.
- [x] **Skills Grouping**: Frontend, Backend (MERN first), Tools, plus lower-emphasis ML & Data row.
- [x] **Featured Projects**: 3-4 featured full-stack / frontend projects with live demo and GitHub code links.
- [x] **5-Section README Case Studies**: Complete `/projects/[slug]` pages with Problem, Architecture, Features, Setup, Improvements.
- [x] **Standout Project**: Haal Khata features offline-first architecture, auth, real-data syncing, and KAIST Grand Prize credentials.
- [x] **Download Resume**: One-click download from Hero BlobButton and dedicated `/resume` preview page.
- [x] **Working Contact Form**: Honeypot anti-spam, Zod validation, rate limiting, and real-time feedback.
- [x] **Admin CMS (`/admin`)**: Protected with JWT authentication, `noindex`, project publish validation, and link health verification.
- [x] **One-Click GitHub Importer**: Automatically imports repository topics, descriptions, and generates draft case studies.
- [x] **Mobile Responsiveness**: Verified across 360px, 768px, 1024px, and 1280px+ viewports with zero horizontal scroll.
